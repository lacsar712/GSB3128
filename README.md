# 智慧教学平台

综合性教学管理平台，涵盖Python课程练习、软件测试题库、Selenium自动化测试课程、云端编程环境及智能考试管理。

## 功能模块

### 1. Python课程练习
- **222道**练习题，涵盖18个分类
- **80%为编程题**，20%为选择题
- 所有练习提供**详细解答**
- 支持在线编程与运行
- 按分类、类型、难度筛选

### 2. 实践项目
- **10个Python实践项目**：学生成绩管理、网络爬虫、文件处理工具、天气查询、个人记账本、密码管理器、图片处理、聊天机器人、任务管理、数据可视化
- **5个课程设计项目**（含2个pygame项目）：贪吃蛇游戏、股票分析系统、企业财务报表生成器、太空射击游戏、能源消耗监控系统
- 涉及领域：游戏、金融、财务、能源等

### 3. 软件测试题库
- **576道**测试题目
- **27%为主观题**（简答题120道 + 填表题36道）
- 客观题包括：单选题180道、多选题84道、判断题120道、匹配题36道
- 涵盖12个测试领域

### 4. Selenium自动化测试课程
- **10章**完整课程大纲
- **16个**教学视频
- 覆盖元素定位、浏览器操作、等待机制、PO模式、测试框架等

### 5. 云端编程环境
- Python在线编程与运行
- Linux终端命令执行
- 实时输出显示

### 6. 智能考试管理
- 创建考试（名称、试卷选择、时长、模式、类型等）
- 试卷校验与样卷预览
- 防作弊设置（切屏限制、全屏模式、禁止复制、摄像头）
- 作答与调试设置
- 判题设置（自动判题、及格分数）
- 添加学生和管理人员
- 考场实时监控
- 成绩统计分析（平均分、最高分、最低分、及格率）
- 人工判卷
- 单题分析（正确率、区分度、难度）
- 成绩导出CSV

## 项目解构 (Project Structure)

```text
label-3128/
├── app.py              # Flask 后端核心逻辑与 API 路由
├── data/               # 核心数据存储 (JSON 格式)
│   ├── exercises.json  # Python 练习题库
│   ├── projects.json   # 实践与课程设计项目
│   ├── questions.json  # 软件测试多维度题库
│   └── selenium.json   # Selenium 自动化课程大纲
├── static/             # 静态资源文件
│   ├── css/            # 页面设计系统 (style.css)
│   └── js/             # 前端交互逻辑 (app.js)
├── templates/          # Jinja2 视图模板
│   └── index.html      # 主控台 SPA 入口
├── Dockerfile          # 应用容器化配置
├── docker-compose.yml  # 一键编排部署配置
├── requirements.txt    # Python 环境依赖列表
└── README.md           # 项目详细说明文档
```

## 技术栈

- **后端**: Python Flask
- **前端**: 原生HTML/CSS/JavaScript
- **部署**: Docker
